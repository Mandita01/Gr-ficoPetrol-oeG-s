# Projeto ANP

Este repositório reúne dados e visualizações relacionadas à análise de informações da ANP (Agência Nacional do Petróleo, Gás Natural e Biocombustíveis). O objetivo do projeto é organizar, interpretar e apresentar indicadores relevantes para consulta e acompanhamento.

## Visão geral

O projeto contém uma base de dados da ANP e uma representação gráfica dos indicadores analisados, com foco em:

- comparações anuais;
- volume de recursos e downloads;
- análise de uso e distribuição dos dados;
- visualização de informações em formato acessível.

## Descrição

Este projeto tem como finalidade apresentar a estrutura e a visualização de dados da ANP em um formato organizado e de fácil consulta. A proposta é permitir uma leitura mais clara de indicadores, padrões de uso e resultados por período e categoria, facilitando a análise dos dados disponibilizados.
